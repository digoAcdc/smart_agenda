Seu código para redefinir a senha
Recebemos um pedido para redefinir a senha da sua conta. Abra o app Smart Agenda no celular e digite este código na tela Esqueci minha senha:
{{ .Token }}
O código vale por 1 hora e só pode ser usado uma vez. Depois de digitá-lo, o app pede a nova senha.
Não pediu para redefinir a senha? É só ignorar este e-mail; sua senha continua a mesma.
